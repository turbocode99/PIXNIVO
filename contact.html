2. Effective Technical Bug Submissions

Because PIXNIVO tools execute directly inside your browser's WebAssembly and JavaScript environment, bugs are often dependent on specific device memory, GPU hardware acceleration, or browser version quirks. When reporting an issue, including the following diagnostics dramatically speeds resolution:

  • Exact Tool & Subview: E.g., PDF Tools (Rotate PDF), AIDC Studio (Batch Generator), or Image Compressor.
  • Browser & Operating System: E.g., Google Chrome 128 on Windows 11, Safari 17.5 on macOS Sonoma, or Mobile Safari on iOS 17.
  • Input File Metadata: Approximate file size (e.g., 18 MB), dimensions (e.g., 4000x3000 px), and format (.png, .webp, .pdf, .csv).
  • Console Output: Any JavaScript warning or red error message visible in the browser developer console (F12 → Console).
