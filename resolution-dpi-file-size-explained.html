Resolution, DPI & File Size Explained in Plain English

24 May 2026•9 min read

Digital imaging terminology can be needlessly confusing. Terms like DPI, PPI, megapixels, resolution, and kilobytes are frequently used interchangeably despite describing distinct physical properties.

Here is a clear guide on the arithmetic connecting pixels to print dimensions and disk storage.

1. Pixels: The Only Unit Screens Understand

A pixel is an individual color dot in a digital grid. An image measuring 1920 × 1080 contains 2,073,600 pixels (roughly 2 Megapixels). On a screen, only pixel count matters.

2. DPI vs PPI: The Print Metric

DPI (Dots Per Inch) and PPI (Pixels Per Inch) describe physical density when converting a digital pixel grid onto physical paper or canvas.

The Universal Print Equation:
Physical Print Width (Inches) = Total Horizontal Pixels ÷ Target DPI
For example: 3000 pixels ÷ 300 DPI = 10 inches of sharp magazine print.

3. File Size (Megabytes vs Megapixels)

Megapixels measures the number of picture elements in the grid. Megabytes measures the storage space required to save that data to disk after compression.
